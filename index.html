Full-stack app deployment: Django and React on EC2

Push to main>GitHub Actions>Docker image>Docker Hub>EC2 (Terraform)

The problem

Deploying a frontend and API by hand is slow and easy to get wrong.

What I built

  • Multi-stage Docker builds for the Django and React apps.
  • Terraform for the EC2 instance, VPC, security groups (ports 80, 443, 22) and networking.
  • GitHub Actions workflow that builds, pushes and triggers the remote deploy on every push to main.
  • Docker Compose to connect the services and manage environment variables.

The result

Production images more than 60% smaller, and deployment with no manual steps.
